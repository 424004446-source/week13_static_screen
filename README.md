## Project Overview
This project is an individual laboratory activity for Week 13 (*Flutter Foundations & Widget Basics - Part 1*). It translates a Week 1–2 Figma Login Screen wireframe into a static Flutter interface using core layout and UI widgets.

## Features & Widgets Used
- **Root & Structure:** `MaterialApp`, `Scaffold`, `AppBar`, and `SafeArea`
- **Layout & Spacing:** `Column`, `Row`, `Container`, `Padding`, and `SizedBox`
- **Content & Styling:** `Text`, `BoxDecoration`, custom borders, and typography
- **Custom Widget:** `LoginScreen` (`StatelessWidget`)
